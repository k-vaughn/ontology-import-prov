# PROV Access and Query Ontology

0.2

NOTE: This ontology has been tweaked to allow it to properly generate the documentation for this site. For example, the ending of the ontology IRI was changed from a `#` to a `/` to allow hyperlinks to work correctly, this note was added, skos:definition annotations were derived from prov:definition (or editorsDefinition/rdfs:comment when definition is absent), and OWL restrictions are serialized inline with their class definitions.
